# HerLens 八类内容特征标注手册

本手册用于产生可复核的女频小说内容标签，不以作品篇幅作为适用限制。标注对象是**文本表达**，不是读者真实情绪、作者动机或市场因果。每个实质标签都必须能回到当前文本版本的原句；多章节作品还必须记录章节级来源和作品级聚合范围。

## 通用记录结构

```json
{
  "group": "包装钩子",
  "value": "身份反差",
  "rationale": "标题同时给出被低估的旧身份和公开的新身份。",
  "evidence_refs": ["ev-001"],
  "review_status": "待审核"
}
```

- `value`：最小、可统计的判断。多标签字段可有多个值。
- `rationale`：解释证据为什么支持该值，不复述标签名。
- `evidence_refs`：指向 `version_id + field + paragraph_id + [start_char,end_char) + quote`。
- `review_status`：`待审核`、`已审核` 或 `需复核`。模型输出默认不是人工金标。
- `unknown`：该字段理论上适用，但当前文本范围或证据不足。
- `not_applicable`：字段在该作品中不适用。例如无人际关系的实验性独白可将“核心关系”标为 `not_applicable`，而不是猜测一个关系。

## 1. 题材语境

**问题：**故事明确发生在什么时代、社会或想象环境中？

**推荐值：**`现代都市`、`现代乡土`、`古代`、`近现代`、`幻想`、`未来/科幻`、`其他`；可多选，但需分别有证据。

- **正例：**文本明确出现当代职场、手机支付与现代法律程序，可标“现代都市”。
- **反例：**因为人名“像古言”就标“古代”；因广告文案中出现“命运”就标“幻想”。
- **`unknown`：**只有无时代线索的抽象标题或一句情绪导语。
- **`not_applicable`：**一般不用；几乎所有叙事都有语境，证据不足应用 `unknown`。

## 2. 叙事驱动力

**问题：**什么持续推动主角行动和主要事件？

**推荐值：**`爱情`、`复仇`、`亲情`、`成长`、`事业`、`悬疑`、`生存`、`其他`。

- **正例：**主角在关系结束后持续经营自己的小店，主要节点都围绕建立新生活，可标“成长／事业”。
- **反例：**男性角色出现了就标“爱情”；一次争吵出现了就标“复仇”。
- **`unknown`：**只知道一个事件，不知道后续行动链。
- **`not_applicable`：**纯非叙事文本且没有行动或事件推进。

## 3. 核心关系

**问题：**哪组人际关系对主要目标和冲突最关键？

**推荐值：**`恋人`、`夫妻/前夫妻`、`母女`、`父女`、`姐妹`、`朋友`、`同事`、`其他`。

- **正例：**标题、导语与开篇都明确围绕两姐妹的遗嘱和未完成对话，可标“姐妹”。
- **反例：**强行为姐妹或职场故事生成“男主／CP”；把一次擦肩而过标为核心关系。
- **`unknown`：**只出现“他／她”且无法确定关系。
- **`not_applicable`：**主要叙事是个体与环境、制度或自身状态的关系，不存在可识别的核心人际关系。

## 4. 主角目标

**问题：**主角想得到、改变、保护或摆脱什么？

**写法：**使用可观察的动词短语，如“离开伤害性关系”、“找到失踪的妹妹”、“保住小店”。

- **正例：**主角签字离婚、搬走并开始独立生计，可标“脱离关系并重建生活”。
- **反例：**“变得更好”、“成为大女主”、“追求幸福”等不可观察形容。
- **`unknown`：**文本只交代处境，没有行动方向。
- **`not_applicable`：**无可识别的主角或非叙事文本。

## 5. 核心冲突

**问题：**谁或什么阻碍目标，触发事件与可观察后果是什么？

**写法：**尽量分开 `阻力来源 + 触发事件 + 后果`。

- **正例：**主角要保住家中店铺，亲属为还债要求卖掉，并已找到买家。
- **反例：**仅用“爱而不得”代替具体阻力；把主角的目标原样当作冲突。
- **`unknown`：**只知道主角想做什么，不知道阻力或后果。
- **`not_applicable`：**非叙事文本，或给定范围明确没有目标—阻力结构。

## 6. 情绪承诺

**问题：**标题与导语让读者预期获得哪种主要情绪取向？

**推荐值：**`甜蜜`、`复仇释放`、`被认可`、`反转`、`释然`、`疗愈`、`紧张/揭秘`、`其他`。

- **正例：**标题先给出离开旧关系，导语紧接着给出新生活动作，可标“释然／自我回收”。
- **反例：**将标题承诺直接写成“读者会感动”；看完结尾后反向美化标题并未表达的承诺。
- **`unknown`：**标题与导语缺失或只有中性事实，无法确定主要情绪取向。
- **`not_applicable`：**包装字段不存在且任务明确不分析包装。

## 7. 包装钩子

**问题：**标题或导语用什么信息结构促使读者继续阅读？

**推荐值：**`冲突前置`、`结果前置`、`结果悬念`、`身份反差`、`关系反差`、`信息缺口`、`时间压力`、`其他`。

- **正例：**标题明确宣布一段关系的结果，导语留下“她为何这样选择”，可标“结果前置／信息缺口”。
- **反例：**只因标题有感叹号就标“冲突前置”；在正文才出现的反差不能算标题钩子。
- **`unknown`：**存在标题但不足以确定一种钩子结构。
- **`not_applicable`：**没有标题和导语，或任务明确排除包装分析。

## 8. 承诺兑现

**问题：**开篇是否建立包装承诺，且在结尾覆盖已确认完整时，结尾如何处理它？

**枚举：**`fulfilled`、`partial`、`contradicted`、`unknown`、`not_applicable`。

- **`fulfilled`：**标题承诺主角脱离伤害性关系，开篇建立离开行动，结尾仍是自主生活；男性角色后悔不等于“复合成功”。
- **`partial`：**开篇建立了主要承诺，结尾处理了一部分，但一个明确子承诺仍未回收。
- **`contradicted`：**标题明确承诺主角做出某种选择，结尾则明确取消该选择，且文本未建立有意反转的新承诺。
- **反例：**为了得到“完整”结果，在只提供开篇时标 `contradicted`；用主观“87 分”代替分类和局限。
- **`unknown`：**仅标题／导语或仅开篇；结尾未确认完整；证据冲突无法裁决。
- **`not_applicable`：**没有可识别的包装承诺，因而无对应对象。

## 证据和审核规则

1. 先分别抽取标题／导语、开篇和结尾，再关联；不得先看结尾后重写标题承诺。
2. 引文偏移是规范化字符串的 Unicode 码点、零起点、左闭右开区间。
3. 后端验证 `source[start_char:end_char] == quote`。重复原句必须同时核对段落与位置，不接受近似引文。
4. 正文变更会使旧证据失效；必须使用新 `content_hash` 重跑对应阶段。
5. 引文精确存在只证明“没有捏造引文”。是否语义支持标签，仍由按本手册的人工抽查判定。
6. 人工修改保留修订号与前后值，并使依赖它的统计和备忘录过期。

## 人工金标的最小要求

- 按作品切分开发集与保留测试集，同一作品不跨集。
- 记录标注者、手册版本、争议和最终裁决。
- 只有一位标注者时如实说明，不称“双盲专家一致”。
- 在金标和分割冻结之前，不报告 micro-F1 或证据支持率；虚构夹具不是模型金标。
