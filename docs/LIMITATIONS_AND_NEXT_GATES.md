# 当前局限与下一道验收门

HerLens 当前能证明的是：不限篇幅的女频小说研究主线可以被做成可交互工作台，证据和指标口径可以被结构化，确定性计算可以回归。它尚不能证明模型对真实女频小说有已测的标签准确率，也不能从小样本推断平台偏好或因果增长。

## 能力状态

| --- | --- | --- | --- |

## 当前数据局限

- 公开样本是 4 篇原创虚构夹具，用于界面、Schema 与数值逻辑，不是抽样调查。
- 本地导入当前实现结构化 JSON 和 UTF-8 TXT；设计书中的 CSV 清单／指标导入尚未实现，不应在演示中声称已支持。
- 虚构指标不得与真实观测汇总，不得写进业务成绩或市场结论。
- 项目尚无可公开的人工金标，因此不报告标签 micro-F1、语义支持率或人类一致性。
- 单一作者样本即使是真实作品，结论也只限于该作者与选样，不能写成“番茄女频用户喜欢”。
- 当前没有随机分组、合格对照或因果识别，标题改版前后的历史比较不称 A/B Test。

## 按价值排序的下一道门

### Gate 1：单部真实作品纵向切片

**输入：**1 部有权本地处理的女频小说，不限篇幅，已确认文本范围和模型外发权。多章节作品还要冻结章节列表、分块覆盖和聚合规则。

**通过条件：**导入 → 一组结构标签 → 可回到章节和原文的精确证据 → 一次人工修订 → 作品级聚合与局限检查 → 一份内容研究报告；所有阶段保留版本和失败记录。匿名本地案例 A 已完成独立全文 CLI 的真实模型抽取、聚合及本地 HTML／Markdown 报告，不是 PPT。人工修订与语义金标尚未完成，CLI 与 Web 存储也尚未打通，因此不声称整个 Gate 已通过。

### Gate 2：小型人工金标

**输入：**目标为至少 10 篇不同作品、30 个标注单元；样本不足则报告实际数。

**通过条件：**codebook 版本冻结；按作品分开开发与保留集；每类标签报告分母、失败、修订与争议案例。达不到目标值不修改金标迎合结果。

### Gate 3：真实指标复盘

**输入：**作品级、版本可匹配、同定义／渠道／窗口／计数单位的观测。

**通过条件：**图表可下钻到原始观测与参数化 SQL；缺失、重叠和不可比样本已显式排除；结论仅称描述性联系，并给出替代解释。

### Gate 4：公开投递版

**通过条件：**上游与新增测试记录完整；演示可离线回放；两个验收视口无溢出和死按钮；隐私扫描没有发现原文、密钥、原始模型负载或私有路径；第三方通知与实际代码来源一致。

## P1：只在 P0 通过后进入

- 人工导入读者反馈笔记，且带来源、日期、授权和研究问题。
- 跨时间样本比较，但先冻结同龄窗口与日历窗口的选择。
- 服务器端 PDF 导出；P0 使用 HTML 打印样式和 Markdown。
- 更细的关系子标签；只在八类核心标签的争议率可控后扩展。

## 明确不做

自动爬取全平台、下载付费内容、推荐模型训练、CTR 预测、爆款排名、复杂多 Agent、向量数据库、自动写完整小说、自动发文和多人 SaaS。若未来需求变更，必须用新的权限、安全和评测设计重新决策，不视为当前 P0 的自然延伸。
