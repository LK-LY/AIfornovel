# HerLens 项目设计（公开版）

## 研究问题

HerLens 是女频小说内容策略工作台。核心问题是：标题与导语承诺了什么，开篇如何建立期待，正文和结尾如何兑现；在观测口径可比时，内容特征与表现有什么描述性联系，下一步应验证什么。

产品不按长篇、短篇设置边界。结论范围由用户提供的文本、版本、证据覆盖和授权决定。亲情、事业、成长、复仇和无 CP 作品不强填恋爱标签。只有开篇时不推断结尾；没有经营数据时不预测点击、付费或“爆款”。

## 用户流程与页面

| 页面 | 核心任务 |
| --- | --- |
| 样本库 | 检查来源、文本范围、授权、版本、指标完整性和审核状态 |
| 作品剖面 | 查看八类候选标签及原文证据，接受、修订或驳回判断 |
| 对比分析 | 检查标签分布、同口径聚合、分母、缺失与排除原因，查看 SQL |
| 研究备忘录 | 组织发现、证据、范围、反例、限制和下一步验证标准 |

八类标注规范见 [CODEBOOK.md](./CODEBOOK.md)。精确引文定位只能证明原句存在，不能替代语义审核。

## 三条执行路径

1. **公共只读演示**：React/Vite 读取原创虚构夹具，不接收上传，不需要模型凭据，也不连接私有数据库。
2. **本地 Web/API 工作流**：FastAPI 与 SQLite 实现导入、版本、标签修订、确定性统计、受限研究工具及 Markdown/HTML/XLSX 导出。Web 导入有 512 KiB 资源上限，不以此给作品划分类别。
3. **独立全文 CLI**：对明确授权的文本进行有界分块、真实模型抽取、逐字引文校验、作品级综合和私有报告生成。它尚未自动写入 Web 样本库。

模型负责提出候选和综合解释；数值由确定性程序或 SQL 计算。研究控制器不暴露任意 shell、SQL 写操作或 URL 抓取能力。详细实现见 [ARCHITECTURE.md](./ARCHITECTURE.md) 与 [NOVEL_ANALYSIS.md](./NOVEL_ANALYSIS.md)。

## 核心数据与校验

- 原文保留不可混淆的版本、内容哈希、规范化规则、段落和 Unicode 码点位置。
- 引文必须属于指定版本和段落，唯一逐字匹配；复合判断仍需按子命题审核。
- 人工修订记录前后值、原因和预期修订号；相关图表及备忘录失效，重算后才能导出。
- CTR 只在定义、渠道、时间窗和计数单位一致时计算 `sum(clicks)/sum(impressions)`；缺失、重叠和累计快照不得混算。
- 全文模型输出通过 Schema 和后验校验；有限修复失败不能改写成成功。缓存指纹包含文本、提示词、契约和执行身份，恢复时重新校验引用。
- 小说中的命令属于不可信文本，不赋予执行权限。

## 发布与隐私

开源仓库只包含应用、测试、契约、技术文档和明确标记的虚构演示数据。原作全文、真实案例报告、模型响应、登录状态、个人材料、数据库和环境文件不发布。

发布采用独立目录、逐文件白名单和隐私检查；Git 提交使用隐私邮箱。公共页面不是多租户服务，本地 API 不应直接暴露公网。详见 [SECURITY.md](../SECURITY.md)。

## 验收与不做事项

测试验证程序、契约和确定性计算；真实模型案例验证一次可追溯的工作流。没有人工金标时，不报告标签准确率、F1 或跨作品泛化能力；单作品研究不推断全平台偏好或因果增长。

当前限制与下一步见 [LIMITATIONS_AND_NEXT_GATES.md](./LIMITATIONS_AND_NEXT_GATES.md)，本机实测见 [VERIFICATION.md](./VERIFICATION.md)。不包含自动抓取全平台、付费内容下载、自动发文、推荐模型训练、CTR 预测或爆款排名。
