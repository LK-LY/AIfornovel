# 真实案例接入清单

真实作品必须从“有权处理”开始，而不是从上传开始。本清单将本地处理、第三方模型外发、公开展示和指标使用拆成独立决定。

本清单适用于任何篇幅的女频小说。对多章节作品，除下列通用字段外，还应冻结章节清单、分块配置、覆盖范围和聚合版本；这些是技术与证据完整性约束，不是将作品排除在产品之外的理由。

## 1. 权限卡

每篇作品单独填写，不得用“我能看到”代替授权。

| 项目 | 选项 | 必填说明 |
| --- | --- | --- |
| 权利人 | 本人 / 他人 / 不确定 | 谁有权同意处理 |
| 本地分析 | 允许 / 不允许 | 是否可解析、分块、存储派生结果 |
| 模型服务 | 允许 / 不允许 / 待确认 | 允许发送的服务、地区、文本范围与保留政策 |
| 公开展示 | 全文 / 节选 / 仅派生结果 / 不允许 | 可展示字数、是否需脱敏、是否需再审 |
| 指标使用 | 允许 / 不允许 | 可否存储、汇总、导出或公开 |
| 撤回与删除 | 日期 / 触发条件 | 如何删除原文、模型原始输出和派生快照 |

任一项不明确时的默认处理：只允许本地结构基准，不调外部模型，不公开原文或派生结果。

## 2. 作品与版本

| 字段 | 要求 |
| --- | --- |
| `work_id` | 不含个人身份信息的稳定 ID |
| `title` | 当前版标题；如需脱敏则另建公开标题 |
| `version_id` | 每次标题、导语或正文变更后新建 |
| `text_scope` | `metadata_only / opening_only / full_text` |
| `ending_confirmed` | 只有确认结尾完整才为 `true` |
| `content_hash` | 对规范化后文本计算，用于证据失效和缓存匹配 |
| `chapter_manifest` | 多章节作品记录章节 ID、码点偏移、分块覆盖与 manifest 哈希；单章节作品可省略 |
| `source_type` | 本人未发表 / 本人已发表 / 获授权他人作品 / 其他 |
| `rights_status` | 与权限卡连接，不写模糊的“可用” |
| `is_synthetic` | 真实作品为 `false`；不与虚构 cohort 混合 |

P0 输入为 UTF-8 TXT 或粘贴文本。如果原文不是 UTF-8，先在私有目录中转换并保留编码记录。不向公开仓库添加原文、复制的版权页或平台截图。

## 3. 指标口径

每条观测与一个内容版本相连。最小信息包括：

- `observation_id`、`work_id`、`version_id`；
- `metric_definition_id` 及书面定义；
- `channel`、`window_spec`、`window_start`、`window_end`；
- `counting_unit` 与原始单位；
- `observation_type = interval | snapshot`；
- 可空的 `impressions / clicks / readers / completions / ctr_reported`；
- 来源和提取日期。

接入前必须能回答：“点击”和“曝光”是人次、设备数还是事件次数？时间窗是发行后同龄窗口还是日历窗口？快照是否累计？某次观测对应哪个标题版本？

如果只有平台显示的 CTR 百分比，保留 `ctr_reported`，不反推曝光或点击；如果版本无法对应，该条只作背景，不进入标题特征比较。

## 4. 运行前数据说明卡

填写一段可放到报告首页的说明：

```text
样本：[谁的作品，共多少篇]
来源：[原文和指标来源]
时间：[作品或观测覆盖日期]
选样：[全量还是按什么规则选取]
排除：[哪些作品或观测被排除以及原因]
可外推范围：[例如仅限该作者、该渠道、该时间窗]
不能回答：[例如不能代表平台用户偏好或因果增长]
```

## 5. 人工审核

1. 按 [`CODEBOOK.md`](./CODEBOOK.md) 确认八类标签的定义，先处理边界案例。
2. 证据存在性检查通过后，再独立判断语义支持。
3. 对每条候选选择“接受／修订／驳回”，记录原因与修订号。
4. 特别检查：非爱情主线是否被强加 CP；“男性后悔”是否被错标为“复合成功”；只有开篇是否被误标为“结尾未兑现”。
5. 报告中的每条发现必须有证据或查询 ID，并写出局限与替代解释。

## 6. 从私有结果到公开案例

公开不是“把一个字段在前端隐藏”。如果获得公开授权，仍应生成独立快照，只包含：

- 已审核且获允许的原句或不可逆的派生摘要；
- 经脱敏的作品 ID；
- 可公开的指标口径与聚合结果；
- 生成日期、样本类型、授权范围与不可外推说明。

公开前从新目录执行一次隐私检查，确认无原文全文、绝对路径、密钥、原始模型请求／响应、平台截图或能反向识别作者的元数据。

## 7. 停止条件

出现以下任一情况就停止对应分支，保留已验证的结果：

- 权利人、模型外发权或公开展示权不明确；
- 指标缺少定义、分母、版本或时间窗；
- 文本版本改变但旧证据尚未失效和重跑；
- 人工审核不能决定证据是否语义支持；
- 报告需要依靠未提供的数字或外部事实才能完整。

正确输出是“当前数据不足以支持该判断，需补充……”，而不是用观感或仿造数字补齐报告。
