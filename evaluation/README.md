# HerLens 评测与回归夹具

这份清单把“原句存在”与“语义支持”分开。当前自动化回归覆盖虚构夹具上的 Schema、证据位置、SQL、修订失效、失败恢复、导出与隐私边界；它们没有被当作真实模型准确率。当次实际命令与结果见 [`docs/VERIFICATION.md`](../docs/VERIFICATION.md)。

```bash
npm test
npm run contracts
npm run snapshot
npm run build
```

## 必测场景

- 全文、仅标题／简介、仅开篇三种覆盖范围。
- 无男主／非爱情主线；结尾离开而不是复合。
- 重复引文、找不到引文、正文改版后旧 evidence 失效。
- 缺曝光量、曝光为零、时间窗重叠、指标定义或渠道不一致。
- 多标签连接前去重，重试／恢复不重复计数。
- 模型返回无效 JSON、单篇失败、任务中途失败和 Key 不进入日志／浏览器。

## 报告时填写

| 项目 | 需要披露 |
| --- | --- |
| Schema 合法性 | 总样本、失败数、修复重试数 |
| 引文可定位 | 已接受、拒绝、无法定位的比例 |
| 标签质量 | 由人工 codebook 形成的 train/test 划分、各标签 micro-F1 |
| 语义支持 | 抽查分母、争议案例、人工修改比例 |
| 数字正确性 | 分母、舍入、缺失、重复连接与参考计算 |
| 报告可信度 | 无引用发现、误引、越界外推清单 |

目标值（不是当前成绩）：结构合法性 100%、已接受证据精确匹配 100%、核心客观标签 micro-F1 ≥ 0.85、人工抽查证据支持率 ≥ 90%。在有权真实女频小说、冻结 codebook 和按作品隔离的人工金标就绪前，上述四项实测数字保持空白；选样不以篇幅作为产品排除条件。
